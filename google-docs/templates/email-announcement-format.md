# Email / memo draft template

Use this when the output should read like a normal email in Google Docs, not like a markdown document.

Subject: <short decision-first subject>

---

Dear <Name>,

Recommendation: <one-sentence recommendation, plain prose>

Context: <one sentence grounding the decision>

<Optional comparison bullets or short labeled lines — avoid pipe tables unless the user explicitly wants a markdown-looking draft.>

Next step: <one short line>

Full report: <linked report title>

Regards,
<Name>

Style reminders:
- Use selective bold only on labels or key terms.
- Do not leave literal markdown markers visible in the final doc.
- Prefer real Google Docs links for URLs.
- If you need a comparison, use short labeled lines or a real table, not pipe syntax.
