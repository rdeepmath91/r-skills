# Editing and Structure Index

Use this index for in-place edits and structure-sensitive operations.

## Primary
- `editing-in-place.md` — targeted section updates and bounded replacements.
- `table-and-element-limitations.md` — table/TOC/page-number/chip constraints.
- `multi-tab-operations.md` — tab-specific workflows for Google Docs with tabs.
- `native-code-blocks.md` — native Code Block constraints, placeholder fills, and fallback workflows.

## Related
- `review-comments.md` — comment-response cycle after editing.
- `api-lessons.md` — known API edge cases impacting structured edits.

## Suggested sequence
1. Plan bounded edits with `editing-in-place.md`.
2. Validate structural constraints (`table-and-element-limitations.md`).
3. If code blocks are involved, decide early: native placeholder fill, UI/manual insertion, whole-doc import, or styled-panel fallback (`native-code-blocks.md`).
4. Apply tab-aware ops when needed (`multi-tab-operations.md`).
5. Close loop with `review-comments.md` and validation checks.
