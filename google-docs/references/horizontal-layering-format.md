# Horizontal layering format for stakeholder docs

Use this when a user asks for cleaner formatting, a wider block, or a diagram that compares layers/components in a boss-facing doc.

## Pattern

Prefer a compact horizontal table or aligned multi-column block when the message is about layering or ownership:

| User / DE / Agent | Wrapper layer | runtime | GL Connectors |
| --- | --- | --- | --- |
| consumer layer | DE + agent wrappers | loads / applies skills | single entry point |

## Rules

- Keep labels short; avoid long stacked vertical boxes unless the stack is the actual point.
- Put the strongest framing in the top row, then explain it in one sentence below.
- Mirror the reference doc's visual framing before rewriting the wording.
- If the doc is meant for a manager or stakeholder, favor scanability over code-like examples.
- After import/export, visually confirm the block still reads left-to-right and does not collapse into a tall narrow stack.
