# Technology / Business section candidate sourcing

Use this when building the weekly report Technology/Business section.

## User preference captured
- Do **not** lock the section to one fixed angle every week.
- Rotate the angle week to week.
- Prefer **one item per angle** rather than multiple items from the same angle.
- When the user asks for alternatives, present candidate items first and wait for selection before inserting them.

## Good angle buckets
- Agent tooling / workflow UX
- Agent safety / prompt injection / evaluation
- Model releases or capability jumps
- Enterprise deployment / adoption stories
- Agent infrastructure / APIs / runtime primitives
- Research or policy items if they are directly about agents

## Reliable official sources to check
- OpenAI News RSS: `https://openai.com/news/rss.xml`
- Google AI blog RSS: `https://blog.google/technology/ai/rss/`
- Anthropic News sitemap: `https://www.anthropic.com/sitemap.xml` filtered to `/news/`

## Selection pattern
1. Pull a short list of current items from official sources.
2. Group by angle.
3. Pick at most one item per angle.
4. If the user wants a choice, show the alternatives with short title + URL first.
5. Only write the final report after the user picks or after you choose a balanced set.
